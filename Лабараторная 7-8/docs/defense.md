# Текст защиты (пример на 5–7 минут)
Здравствуйте. Тема моего мини-проекта — «Контроль качества пищевой продукции». Я разработал веб-приложение QualityControl на HTML, CSS и JavaScript.

**Цель проекта** — показать, как можно автоматизировать первичную проверку введённых показателей партии продукта и выделять значения, которые выходят за заданные диапазоны.

Предметная область связана с регистрацией показателей пищевой продукции. Пользователь вводит название продукта, номер партии, выбирает категорию и указывает температуру, pH, массу упаковки и результат визуального осмотра. Затем приложение сравнивает данные с диапазонами и формирует отчёт.

Перед разработкой я рассмотрел три подхода: электронные таблицы, веб-формы с проверкой ввода и специализированные системы управления качеством. Таблицы гибкие, но требуют настройки формул. Веб-форма удобна для стандартизированного ввода. Специализированные системы имеют больше возможностей, но для небольшого учебного проекта они сложнее. Поэтому я выбрал веб-приложение.

Для жизненного цикла я выбрал инкрементную модель. Сначала подготовил форму, затем добавил проверку диапазонов, отчёт, журнал и тестовые сценарии. Это позволило разрабатывать и проверять приложение по частям.

В программе используются функции для отображения диапазонов, проверки данных, создания отчёта и обновления истории. Объекты хранят диапазоны и данные проверки, массив используется для истории, а методы `map`, `filter` и `every` помогают обрабатывать коллекции. Также применяются условия, проверки ввода и обработка строк.

Сейчас покажу работу. Я ввожу тестовое название продукта и номер партии, указываю значения в учебных диапазонах и запускаю проверку. Система показывает результат каждого показателя. Если температура выходит за диапазон или при визуальном осмотре отмечено отклонение, система выделяет проблему и меняет общий статус. Результаты отображаются в журнале, а счётчики обновляются.

Я подготовил десять тест-кейсов: основные сценарии, ошибки ввода и граничные значения. Их необходимо выполнить в браузере и внести фактические результаты перед окончательной сдачей.

Важное ограничение проекта: диапазоны используются только для демонстрации алгоритма. Они не являются официальными нормативами и не подтверждают безопасность реального продукта. Программа не заменяет лабораторные исследования.

В дальнейшем можно добавить базу данных, авторизацию, экспорт отчёта и настройку нормативов ответственным сотрудником.

В результате я получил работающий учебный прототип, который демонстрирует применение HTML, CSS и JavaScript для ввода, проверки и представления структурированных данных. Спасибо за внимание.
