# Тест-кейсы QualityControl
Перед сдачей выполните тесты в браузере и заполните колонку «Фактический результат». Статус PASS ставится только после фактической проверки.

| ID | Сценарий / входные данные | Ожидаемый результат | Фактический результат | Статус |
|---|---|---|---|---|
| T-01 | Охлаждённый продукт: температура 4 °C, pH 6, масса 500 г, номинальная масса 500 г, осмотр без отклонений | Все показатели проходят; общий результат успешный | Заполнить после проверки | Не проверен |
| T-02 | Температура 8 °C для категории «Охлаждённый продукт» | Температура помечена как отклонение | Заполнить после проверки | Не проверен |
| T-03 | pH = 15 | Система показывает ошибку ввода; отчёт не создаётся | Заполнить после проверки | Не проверен |
| T-04 | Масса = 0 | Система показывает ошибку ввода; отчёт не создаётся | Заполнить после проверки | Не проверен |
| T-05 | Пустое название продукта | Браузер не отправляет форму и просит заполнить поле | Заполнить после проверки | Не проверен |
| T-06 | Пустой номер партии | Браузер не отправляет форму и просит заполнить поле | Заполнить после проверки | Не проверен |
| T-07 | Температура ровно на нижней границе выбранного диапазона | Граничное значение считается допустимым | Заполнить после проверки | Не проверен |
| T-08 | Температура ровно на верхней границе выбранного диапазона | Граничное значение считается допустимым | Заполнить после проверки | Не проверен |
| T-09 | Отмечено «Обнаружены отклонения», остальные показатели в диапазоне | Визуальный осмотр отмечен как отклонение; общий результат отрицательный | Заполнить после проверки | Не проверен |
| T-10 | Выполнить две проверки подряд | Счётчики и журнал содержат две записи в порядке от новой к старой | Заполнить после проверки | Не проверен |

## Примечание
Диапазоны и ожидаемые результаты являются учебными. Эти тесты проверяют логику веб-приложения, а не безопасность реальных продуктов.
