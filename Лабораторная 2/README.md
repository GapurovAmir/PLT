Цель работы

Освоить базовый синтаксис Python, переменные, типы данных, ввод и вывод данных, преобразование типов и арифметические операции.

Условие задания

Ввести трехзначное число. Найти сумму и произведение его цифр.

Входные данные

Одно трехзначное целое число.

Выходные данные

цифра сотен;

цифра десятков;

цифра единиц;

сумма цифр;

произведение цифр.

Алгоритм решения

Ввести трехзначное число.

Получить цифру сотен с помощью оператора //.

Получить цифру десятков с помощью комбинации // и %.

Получить цифру единиц с помощью оператора %.

Вычислить сумму цифр.

Вычислить произведение цифр.

Вывести результаты.

Исходный код
number = int(input("Введите трехзначное число: "))

hundreds = number // 100
tens = number // 10 % 10
units = number % 10

sum_digits = hundreds + tens + units
product_digits = hundreds * tens * units

print("Сотни:", hundreds)
print("Десятки:", tens)
print("Единицы:", units)
print("Сумма цифр:", sum_digits)
print("Произведение цифр:", product_digits)

Вывод

В ходе лабораторной работы были изучены базовые конструкции языка Python. Была создана программа для получения цифр трехзначного числа и вычисления их суммы и произведения. В программе использовались целочисленное деление //, остаток от деления %, преобразование типов с помощью int(), а также функции input() и print().

Контрольные вопросы

Что представляет собой переменная в Python?
Переменная — это имя, связанное с определенным значением.

Какие основные типы данных используются в Python?
int, float, str, bool и другие.

Чем int отличается от float?
int хранит целые числа, а float — числа с дробной частью.

Как работает функция input()?
Она получает данные, введенные пользователем, и возвращает их в виде строки.

Почему результат input() часто необходимо преобразовывать?
Потому что input() возвращает строку, а для математических операций нужны числовые типы.

Для чего используются int() и float()?
Для преобразования значения соответственно в целое число и число с плавающей точкой.

Чем / отличается от //?
/ выполняет обычное деление, а // — целочисленное деление с округлением вниз.

Что делает оператор %?
Возвращает остаток от деления.

**Для чего используется оператор ?
Для возведения числа в степень.

Как определить тип переменной с помощью type()?
Например: type(number).

Что такое преобразование типов?
Это изменение значения из одного типа данных в другой.

Что произойдет при попытке int("Python")?
Возникнет ошибка ValueError, потому что строку "Python" нельзя преобразовать в целое число.

Как получить последнюю цифру целого числа?
Использовать оператор % 10: number % 10.

Как удалить последнюю цифру целого числа?
Использовать целочисленное деление на 10: number // 10.

Почему выбор правильного типа данных важен?
Потому что тип данных определяет, какие значения можно хранить и какие операции можно выполнять с ними.
