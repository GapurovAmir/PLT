Цель работы

Освоить использование переменных, функций input() и print(), преобразование типов и арифметические операции в Python.

Условие

Ввести количество километров. Перевести расстояние в метры, сантиметры и миллиметры.

Входные данные

Количество километров.

Выходные данные

Расстояние в метрах, сантиметрах и миллиметрах.

Алгоритм

Ввести количество километров.

Умножить количество километров на 1000 для получения метров.

Умножить количество километров на 100000 для получения сантиметров.

Умножить количество километров на 1000000 для получения миллиметров.

Вывести результаты.

Исходный код
kilometers = float(input("Введите количество километров: "))

meters = kilometers * 1000
centimeters = kilometers * 100000
millimeters = kilometers * 1000000

print("Метры:", meters)
print("Сантиметры:", centimeters)
print("Миллиметры:", millimeters)
