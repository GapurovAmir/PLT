# Лабораторная работа №3: Основы ООП в Python

**Дисциплина:** «Языки и технология программирования»  
**Вариант:** №8 (Класс Product)  

## Описание проекта
Проект посвящен изучению базовых принципов объектно-ориентированного программирования в Python: создание классов, конструктора `__init__`, атрибутов, методов, принципа инкапсуляции и работы с объектами.

## Структура проекта
* `lab3.py` — основной файл с реализацией класса `Product` и тестовыми сценариями.
* `readme.md` — файл с описанием лабораторной работы.

## Реализованный класс: Product
* **Атрибуты:**
  * `name` (публичный) — название товара.
  * `__price` (закрытый) — цена товара (инкапсуляция).
  * `quantity` (публичный) — количество на складе.
  * `category` (публичный, доп. задание) — категория товара.
* **Методы:**
  * `change_price(new_price)` — изменение цены с проверкой на валидность.
  * `add_quantity(amount)` — пополнение запасов на складе.
  * `get_total_value()` — расчет общей стоимости запасов.
  * `apply_discount(percent)` — применение скидки (доп. задание).
  * `get_price()` — геттер для получения закрытой цены.
