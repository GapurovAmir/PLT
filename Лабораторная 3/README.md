Цель работы

Освоить создание классов и объектов в Python, использование конструктора __init__(), атрибутов, методов и self.

Задание

Создать класс Student, содержащий имя, возраст и специальность. Реализовать вывод информации о студенте и изменение специальности.

Реализация

В программе создан класс Student со следующими атрибутами:

name — имя студента;

age — возраст;

specialty — специальность;

course — курс.

Методы класса:

show_info() — вывод информации о студенте;

change_specialty() — изменение специальности;

change_course() — изменение курса;

birthday() — увеличение возраста на один год.

В программе создано три объекта класса Student.

Тестирование
Тест 1

Вывод информации о студенте.

Тест 2

Изменение специальности студента.

Тест 3

Изменение курса и увеличение возраста студента.
